# 카카오 채널 마도저항 계산 스킬

Python 표준 라이브러리만 사용하는 카카오 i 오픈빌더 스킬 서버입니다.

## 실행

Python 3.10 이상에서 실행합니다.

```powershell
python app.py
```

서버는 로컬에서 `http://0.0.0.0:8000/skill`로 POST 요청을 받습니다. Render에서는 `PORT` 환경 변수를 자동으로 사용합니다. Render에 배포하면 발급되는 HTTPS 주소 뒤에 `/skill`을 붙여 오픈빌더 스킬 URL로 지정하세요.

## Render 배포

1. GitHub 저장소에 `app.py`, `requirements.txt`, `README.md`를 저장소 최상위에 올립니다.
2. Render에서 **New → Web Service**를 선택해 GitHub 저장소를 연결합니다.
3. **Root Directory**는 비워 둡니다.
4. **Runtime**은 `Python 3`, **Build Command**는 `pip install -r requirements.txt`, **Start Command**는 `python app.py`로 지정합니다.
5. Free 인스턴스를 선택하고 배포합니다. 배포 후 `https://서비스이름.onrender.com/`에 접속해 실행 안내 문구가 보이는지 확인합니다.
6. 오픈빌더 스킬 URL에는 `https://서비스이름.onrender.com/skill`을 입력합니다.

Render 무료 웹 서비스는 15분 동안 요청이 없으면 잠들 수 있으며, 다시 요청이 오면 깨어나는 시간이 필요할 수 있습니다.

## 명령어

오픈빌더에서 스킬이 연결된 블록으로 다음 발화를 보내도록 설정합니다.

```text
!마도 3200 4000
!마도저항 3200 4000
```

두 숫자는 순서대로 내 마도저항과 마도 압력입니다. 필요 저항은 입장 조건이므로 이 계산에는 넣지 않습니다.

## 적용한 공식

- 차이 = 내 마도저항 − 마도 압력
- 차이가 음수일 때 주는 피해 배율 = `0.5 ** (부족분 / 1,000)`
- 차이가 양수일 때 주는 피해 배율 = `1 + 0.5 × (1 − 0.5 ** (초과분 / 4,000))`
- 차이가 음수일 때 받는 피해 배율 = `1 + (부족분 / 1,000) ** 0.75`
- 차이가 0 이상일 때 받는 피해 배율 = `1`

거듭제곱 표기는 질문에 적힌 0.5의 부족분/초과분 지수로 해석했습니다. 콘텐츠 데이터 값은 게임 데이터 3.4.40011 기준이며, 서버는 콘텐츠별 값 조회 없이 입력받은 수치만 계산합니다.
